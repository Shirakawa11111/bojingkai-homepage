# bojingkai-homepage

个人主页静态站项目，面向 `bojingkai.com` 部署。

## 文件结构

- `index.html`: 单页内容结构
- `styles.css`: 设计 token、布局、组件与响应式样式

## 本地预览

直接在浏览器中打开 `index.html` 即可预览。

## 部署建议

可直接部署到 Cloudflare Pages、GitHub Pages 或任何静态文件托管服务。

## 邮箱路由

公开联系地址可使用 `tech@bojingkai.com`。如果你希望 `@bojingkai.com` 的任意地址都转发到你的 Gmail，建议使用 Cloudflare Email Routing 的 catch-all 规则。
